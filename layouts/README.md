# Community layouts

Layouts shared by PitGlass users. To use one, download the `.pitglass.json` file and load it with **Import layout…** in the control panel.

To share yours:

1. In the control panel, press **Export** on your layout.
2. Add the file to this folder, named after what it is for (`ets2-night-bus.pitglass.json`).
3. Put your name in the `author` field and open a pull request. A screenshot in the description helps.

Please only send layouts you drew yourself. Dashboards exported from other programs belong to their authors.

The file format is described in [docs/LAYOUTS.md](../docs/LAYOUTS.md).
